# Artwork pipeline

Everything in `temporary/` is original procedural placeholder artwork generated by
`scripts/generate_placeholders.py`. It is intentionally replaceable and is not
approved final production art. The character faces the viewer and has neutral,
blink and jump poses. It is a provisional representation, not a portrait likeness.

Scene layers share a 960 × 540 coordinate system. Character poses are 48 × 80 with
a bottom-center anchor. Replace one layer at a time using `src/assets/manifest.ts`;
keep dimensions and anchors or update the manifest/config together. Use transparent
PNG for layers and nearest-neighbor sampling. Never bake the entire scene into one
image: the composite poster is only the static reduced-motion/WebGL fallback.

The approximately five-color theme is allowed controlled shade ramps, not unrelated
accent hues. No stock photos or image-generation service are used.

`production/` is reserved for art approved in a later milestone.
